# 恆永顧問內部系統 · High-fidelity Prototype

PRD v1.0 第 3 節（AI 功能除外）的桌機版互動 prototype。所有資料為示意資料，存在瀏覽器記憶體中，重新整理即回到初始狀態。

## 開發與部署

```bash
npm install
npm run dev        # 本機開發 http://localhost:5173
npm run build      # 產出 dist/
```

Vercel：Framework Preset 選 **Vite**，Build Command `npm run build`，Output Directory `dist`。不需要環境變數。

## 畫面規格（Visual PRD）

`/spec` 列出所有畫面：左側嵌入可操作的 prototype，右側為功能、User Flow 與對應的 PRD v1.0 節次。內容定義在 `src/spec/screens.ts`。

prototype 支援網址參數直接開到指定狀態，例如 `/?as=exec1&page=case&id=SINJI-ISCC-2026-01&tab=finance`（`as` 角色帳號、`page`／`id`／`tab` 頁面、`open` 彈窗）。

## 示範設定

- Prototype 的「今天」固定為 **2026/10/29（週四）**，讓提醒天數可重現（`src/lib/utils.ts` 的 `TODAY`）。
- 預設以 **經營層（擁有者）** 登入。右上角「檢視角色」或左下角帳號卡可依角色切換（經營層／合夥人／行政／財務／顧問／外部顧問），不需要記得哪位同仁是什麼職位。角色對應的示範帳號定義在 `src/lib/store.tsx` 的 `DEMO_ROLES`。
- 僅支援桌機寬度（最小 1280px），未做 RWD。

## 建議示範路徑

1. **邀請與權限**：設定 → 成員與權限 → 邀請成員 → 寄送 → 點「模擬開啟邀請連結」→ 以受邀者身分完成個人資料 → 進入工作空間。切回經營層，在成員頁點任一人，右側抽屜用開關調整權限。
2. **審核流程**：案件 → `TAIYA-仁武廠-ISO14064-2026-01` → 概覽「企劃書審核與報價」→ 核可報價，狀態轉為「已報價待回簽」，通知自動完成。
3. **退回後修改**：切換成顧問 → `JIAHE-ISO14067-2026-01`，可看到核價退回意見，修改報價後重新送出。
4. **進度登記與行事曆候選**：以行政角色開啟 `SENMAO-FSC-2026-01`，可登記拜訪日（顧問角色只看得到自己負責的案件）。
5. **堂數不符**：`SINJI-ISCC-2026-01` → 排課分頁（行事曆 7 堂、合約 6 堂）。
6. **權限缺口**：以經營層或行政開啟 `GUANGCAI-GRS-2026-01` → 文件分頁，會看到負責顧問尚未加入共用名單的提示。
7. **Gmail 擴充功能**：左側「Gmail 擴充功能」→ 打開信件確認歸檔；「詢問 ISO 14064-1 碳盤查輔導」示範從新客戶的信建立案件。
8. **開票與收款**：財務中心 → 開票待辦 → 登記開立；請款總表可直接編輯發票號碼與日期；匯出待開發票清單。
9. **差旅費**：切換成顧問 → 差旅費 → 新增，日期選 10/27 可看到多個候選案件。
10. **續證**：`DAYU-ISO22716-2025-01`（27 天到期）→ 建立續證案件，或由經營層標記本次不續證。

## 結構

```
src/
  lib/        型別、示意資料、權限範本、提醒規則、狀態推導、store
  components/ UI 元件、App shell、財務共用 modal
  pages/      各頁面；cases/tabs 為案件詳情的各分頁
```

案件狀態不存欄位，一律由里程碑日期與審核進度推導（`deriveStatus`）；15 種通知依 PRD 3.11 規則即時計算（`computeNotifications`），完成條件成立時自動轉為已完成。
